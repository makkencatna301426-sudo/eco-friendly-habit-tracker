# Eco-Friendly Habit Tracker System

A web-based application designed to help users track sustainable daily habits, monitor eco-points and streaks, and visualize environmental impact metrics (such as CO2 reduction). Developed as the SDF04 Final Project.

---

## 🚀 Features
* **User Authentication:** Secure registration and login for personalized user sessions.
* **Habit Management:** Create, update, toggle completion, and delete sustainable habits.
* **Quick Action Logger:** Instantly log impromptu eco-friendly actions (e.g., recycling, zero-waste shopping).
* **Interactive Dashboard & Reports:** Visualize daily activity logs, impact summaries, and performance metrics using Chart.js.

---

## 🛠️ Technology Stack
* **Back-End:** Python, Flask, Flask-SQLAlchemy, PyMySQL
* **Database:** MySQL (Hosted via XAMPP `midproj` database)
* **Front-End:** HTML5, Tailwind CSS, JavaScript, Chart.js
* **Version Control:** Git & GitHub
